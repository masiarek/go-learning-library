# `reflect` reads struct tags

**Level:** 301 · anyone writing a validator, an encoder or a flag binder that works from struct fields

**One line:** A struct tag is a string the compiler keeps with its field, and `reflect.TypeOf(v).Field(i).Tag.Get("json")` reads it at run time — the same read `encoding/json` does — while `Kind` says what shape a type has (`float64`) and `Type` says which type it is (`main.Celsius`).

An `Invoice` carries two kinds of tag: `json:"…"` for the encoder and `validate:"required"` for a fifteen-line validator written here. The program walks the fields with `reflect.Type`, prints each tag as `Get` and `Lookup` see it, runs the validator on a complete and an empty invoice, marshals both, marshals a struct with no exported fields at all, and then puts `Type` and `Kind` side by side on a named float type.

## Reading the output

**Five fields, and the tags exactly as written.** `reflect.TypeOf(Invoice{})` describes the type, `NumField` counts its fields and `Field(i)` returns a [`StructField` ↗](https://pkg.go.dev/reflect#StructField) whose `Tag` is the raw string between the backticks. [`Tag.Get(key)` ↗](https://pkg.go.dev/reflect#StructTag.Get) returns the value for a key, or `""` when the key is absent — which is why `Amount`'s `validate` reads as `""` — and [`Tag.Lookup` ↗](https://pkg.go.dev/reflect#StructTag.Lookup) adds the boolean that tells an absent key from an empty value. The format `Get` parses is a space-separated list of `key:"value"` pairs; a tag that does not fit it is silently unreadable, and only `go vet` notices ([`structtag`](../reflection_vet_and_lints/README.md)).

**The validator is `Tag.Get` plus `IsZero`.** `missing` pairs the type's fields with the value's: `rt.Field(i).Tag.Get("validate") == "required"` selects the rule, and [`rv.Field(i).IsZero()` ↗](https://pkg.go.dev/reflect#Value.IsZero) tests the value. The empty invoice fails on `Number` and `Customer`; `Amount` has no rule, so its `99` is neither here nor there.

**`json.Marshal` reads the same tags.** The [`encoding/json` ↗](https://pkg.go.dev/encoding/json#Marshal) rules are visible in the two JSON lines: `number` and `amount` are the names from the tags, `customer,omitempty` drops the key when the field is empty (the second line has no `customer`), and `-` removes `Note` from both. Field order in the JSON is the struct's field order, which is why this output is a key and a map's would not be. `draft` never appears, and neither does anything from `ledger`: the encoder can only see exported fields, so a struct with none marshals as `{}` with no error. No tool warns about that ([What no tool catches](../reflection_vet_and_lints/README.md)).

**`Kind` is the shape, `Type` is the name.** `Celsius` is declared as `type Celsius float64`. Its `Type` prints as `main.Celsius`, its `Name` is `Celsius`, and it is *not* equal to `reflect.TypeOf(float64(0))` — they are different types, and a type switch on `float64` will not match a `Celsius`. Its [`Kind` ↗](https://pkg.go.dev/reflect#Kind) is `float64`, one of the fixed set of shapes (`Int`, `String`, `Struct`, `Pointer`, `Slice`, …), and it equals `reflect.Float64`. Code that wants to handle "any float" checks the `Kind`; code that wants to handle `Celsius` checks the `Type`. A pointer's `Kind` prints as `ptr`, and `Elem` is the type it points at.

**The three laws.** Rob Pike's [*The Laws of Reflection* ↗](https://go.dev/blog/laws-of-reflection) are the last block. Law one: reflection goes from an interface value to a reflection object — `reflect.ValueOf(reading)` takes an `any`, and the two words of that interface ([An interface is two words](../../11_Interfaces_and_Method_Sets/an_interface_is_two_words/README.md)) are what `Value` keeps. Law two: it goes back — `v.Interface()` returns an `any` whose dynamic type is still `main.Celsius`, so the type assertion to `Celsius` succeeds. Law three: to modify a reflection object, the value must be settable — and `CanSet` is `false` here, because `ValueOf` was handed a copy. That law is the [next lesson](../reflect_sets_only_addressable_values/README.md).

```go
// reflect reads a struct's field tags at run time: the same key:"value" strings
// that encoding/json reads to name the JSON keys. A Type says which type a
// value has; its Kind says only what shape that type is.
//
//	go build reflect_reads_struct_tags_go.go && ./reflect_reads_struct_tags_go
package main

import (
	"encoding/json"
	"fmt"
	"reflect"
	"strings"
)

// An Invoice as a JSON encoder and a validator see it: through its tags.
type Invoice struct {
	Number   string  `json:"number" validate:"required"`
	Customer string  `json:"customer,omitempty" validate:"required"`
	Amount   float64 `json:"amount"`
	Note     string  `json:"-"`
	draft    bool    // unexported: no tag, and json.Marshal never sees it
}

// A ledger with no exported fields at all.
type ledger struct {
	balance int
	owner   string
}

// Celsius is its own type; its kind is float64.
type Celsius float64

func main() {
	t := reflect.TypeOf(Invoice{})
	fmt.Printf("%s has %d fields:\n", t, t.NumField())
	for i := range t.NumField() {
		f := t.Field(i)
		rule, tagged := f.Tag.Lookup("validate")
		fmt.Printf("  %-8s exported %-5t json=%-21q validate=%q (tag present %t)\n",
			f.Name, f.IsExported(), f.Tag.Get("json"), rule, tagged)
	}

	paid := Invoice{Number: "INV-1001", Customer: "Ada Lovelace", Amount: 1250.5, Note: "net 30", draft: true}
	blank := Invoice{Amount: 99}
	fmt.Println("required fields missing in paid: ", missing(paid))
	fmt.Println("required fields missing in blank:", missing(blank))

	for _, inv := range []Invoice{paid, blank} {
		data, err := json.Marshal(inv)
		fmt.Printf("json.Marshal: %s (err %v)\n", data, err)
	}
	data, err := json.Marshal(ledger{balance: 10, owner: "Ada"})
	fmt.Printf("json.Marshal of a struct with only unexported fields: %s (err %v)\n", data, err)

	var reading Celsius = 21.5
	ct := reflect.TypeOf(reading)
	fmt.Printf("Celsius: Type %s, Name %q, Kind %s\n", ct, ct.Name(), ct.Kind())
	fmt.Println("  Type == TypeOf(float64):", ct == reflect.TypeOf(float64(0)))
	fmt.Println("  Kind == reflect.Float64:", ct.Kind() == reflect.Float64)
	fmt.Println("  Kind of *Celsius:", reflect.TypeOf(&reading).Kind(), " Elem:", reflect.TypeOf(&reading).Elem())

	// The three laws: an interface value in, a reflection object, and back out.
	var v reflect.Value = reflect.ValueOf(reading) // law 1: interface value -> Value
	back := v.Interface()                          // law 2: Value -> interface value
	c, ok := back.(Celsius)                        // the dynamic type is still Celsius
	fmt.Printf("round trip: %v %T, Celsius %t, CanSet %t\n", back, back, ok, v.CanSet())
	_ = c
}

// missing names the fields tagged validate:"required" that hold their zero value.
func missing(v any) string {
	rv := reflect.ValueOf(v)
	rt := rv.Type()
	var names []string
	for i := range rt.NumField() {
		if rt.Field(i).Tag.Get("validate") == "required" && rv.Field(i).IsZero() {
			names = append(names, rt.Field(i).Name)
		}
	}
	if len(names) == 0 {
		return "none"
	}
	return strings.Join(names, ", ")
}
```

## What to do

- **Read tags with `Lookup` when "no tag" and "empty tag" mean different things**, and with `Get` when they do not. Both are cheap: a tag is a string the compiler stored, and there is nothing to parse until you ask.
- **Check `Kind` before calling a Kind-specific method.** `NumField` on a non-struct, `Int` on a string and `Elem` on an int are run-time panics, listed on [the compiler errors page](../reflection_compiler_errors/README.md) because the compiler cannot see them.
- **Switch on `Type` for a named type and on `Kind` for a shape.** `reflect.TypeOf(x) == reflect.TypeFor[Celsius]()` is a type test; `Kind() == reflect.Float64` accepts every float type ever declared.
- **Export the fields you want an encoder to see.** `json.Marshal` skips unexported fields silently; a struct that comes out as `{}` has usually lost a capital letter.
- **Keep the tag format exact** — `key:"value"`, space-separated — and run `go vet`: the compiler accepts any string.

## Practice

An `Order` has an `ID int` tagged `csv:"order_id"`, a `Customer string` tagged `csv:"customer"`, an untagged `Total float64`, a `Secret string` tagged `csv:"-"` and an unexported field. Write `csvLines(v any) (header, row string, err error)` that returns the header line of CSV column names — the tag's value, or the field name when there is no tag, skipping `-` and unexported fields — and one row of the values, and returns an error rather than panicking when `v` is not a struct.

```go
// Kata: a CSV header and one row from struct tags. Each exported field gives a
// column named by its csv tag, or by the field name when it has no tag; a
// field tagged csv:"-" gives no column, and an unexported field is skipped.
//
//	go build reflect_reads_struct_tags_kata_go.go && ./reflect_reads_struct_tags_kata_go
package main

import (
	"fmt"
	"reflect"
	"strings"
)

type Order struct {
	ID       int     `csv:"order_id"`
	Customer string  `csv:"customer"`
	Total    float64 // no tag: the column is called Total
	Secret   string  `csv:"-"`
	internal string  `csv:"never_seen"`
}

// columns returns the CSV column for each field of v, and the field index it came from.
func columns(t reflect.Type) (names []string, fields []int) {
	for i := range t.NumField() {
		f := t.Field(i)
		if !f.IsExported() {
			continue
		}
		name, tagged := f.Tag.Lookup("csv")
		if !tagged {
			name = f.Name
		}
		if name == "-" {
			continue
		}
		names = append(names, name)
		fields = append(fields, i)
	}
	return names, fields
}

func csvLines(v any) (header, row string, err error) {
	rv := reflect.ValueOf(v)
	if rv.Kind() != reflect.Struct {
		return "", "", fmt.Errorf("csvLines: got %s (kind %s), not a struct", rv.Type(), rv.Kind())
	}
	names, fields := columns(rv.Type())
	cells := make([]string, len(fields))
	for i, f := range fields {
		cells[i] = fmt.Sprint(rv.Field(f).Interface())
	}
	return strings.Join(names, ","), strings.Join(cells, ","), nil
}

func main() {
	order := Order{ID: 7, Customer: "Ada", Total: 19.5, Secret: "pin 1234", internal: "x"}
	header, row, err := csvLines(order)
	fmt.Println(header)
	fmt.Println(row)
	fmt.Println("err:", err)

	_, _, err = csvLines(42)
	fmt.Println("err:", err)
}
```

## In other languages

- **Rust** has no run-time reflection: `serde` reads its `#[serde(rename = "…")]` attributes at compile time, inside a derive macro. The Rust library's [Three kinds of procedural macro ↗](https://masiarek.github.io/rust-learning-library/37_Procedural_Macros/three_kinds_of_procedural_macro/index.html) is the mechanism, and [A `StateMachine` derive ↗](https://masiarek.github.io/rust-learning-library/37_Procedural_Macros/a_state_machine_derive/index.html) reads per-variant attributes the way this page reads per-field tags — except that a malformed attribute there is a compile error at the attribute, where a malformed tag here is a string `Get` cannot parse.
- **Python**'s [`dataclasses.fields()` ↗](https://docs.python.org/3/library/dataclasses.html#dataclasses.fields) gives each field's name, type and a `metadata` mapping that plays the role of a tag; there is no compile step to keep the metadata with the field, it is stored in the class at import time.
- **Java** keeps annotations with the field the way Go keeps tags, and [`Field.getAnnotation` ↗](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/reflect/Field.html) reads them at run time; a Jackson `@JsonProperty("name")` is the `json:"name"` of this page, typed and checked by the compiler rather than a string.
