# A generic type and its zero value

**Level:** 201 · anyone writing their first `Stack[T]`

**One line:** `Stack[int]` and `Stack[string]` are two distinct types made from one declaration, and `%T` prints each with its type argument — `main.Stack[int]`, `main.Pair[string,float64]` with no space after the comma, `main.Stack[[]uint8]` for a `Stack[[]byte]`; inside a method the zero value of `T` is spelled `var zero T` or `*new(T)`, and it is what `Pop` on an empty stack returns beside `false`.

A `Stack[T any]` with `Push`, `Pop` and `Peek`; a `Set[T comparable]` on a map; a `Pair[K, V]`. They are used with strings, floats, pointers, a byte slice and a stack of stacks, so that the instantiated type names show.

## Reading the output

**`Pop` on an empty `Stack[string]` returns `""` and `false`.** `var zero T` declares a variable of the type parameter's type and leaves it at its [zero value ↗](https://go.dev/ref/spec#The_zero_value). No literal would do: `""` is wrong for a `Stack[int]`, `0` for a `Stack[string]`, `nil` for both — and the method body is checked once for every `T` in the set, so the only spelling that is right for all of them is the one that names none. The `bool` beside it is how a caller tells the zero value from a stored `""`; [`cmp.Or` ↗](https://github.com/golang/go/blob/go1.25.5/src/cmp/cmp.go) in the standard library is written the same way.

**`*new(T)` is the same value.** `new(T)` allocates a zeroed `T` and returns a `*T` ([spec ↗](https://go.dev/ref/spec#Allocation)); dereferencing it yields the value, which is what `Peek` returns for an empty `Stack[float64]`: `0`. It is the one-expression spelling; `var zero T` reads plainer.

**`Pop` on an empty `Stack[*string]` returns `<nil>`** — the zero value of a pointer type. A stored nil pointer would print the same, which is why `Pop` has its second result.

**A `Set` needs `comparable`.** `map[T]struct{}` is a legal type only when `T` can be a map key — the [spec ↗](https://go.dev/ref/spec#Map_types) requires `==` to be fully defined on the key type — so with `T any` the declaration itself is refused: the driver's first line below, `invalid map key type T (missing comparable constraint)`. The constraint is part of the type's contract, checked at every instantiation: `Set[string]` is fine, `Set[[]byte]` would be `[]byte does not satisfy comparable` ([the compiler errors page](../generics_compiler_errors/README.md)).

**`%T` names the instantiated type.** `main.Stack[string]`, `*main.Stack[float64]`, `main.Set[string]`, `main.Pair[string,float64]`: package-qualified, type arguments in brackets, and no space after the comma between two arguments — the spelling `reflect.Type`'s `String` produces and [`%T` ↗](https://pkg.go.dev/fmt#hdr-Printing) prints. `Stack[[]byte]` prints as `main.Stack[[]uint8]` because `byte` is an alias for `uint8` ([spec ↗](https://go.dev/ref/spec#Numeric_types)) and an alias has no name of its own at run time. `Stack[Stack[int]]` nests as you would write it. The strings are the same on the Linux runner — CI holds the key on both machines. `%v` of a zero `Stack[int]` is `{[]}`, a struct holding one nil slice.

`var invoices Stack` names the template, not a type; `Pair[string]` supplies one of two arguments and `Stack[int, string]` two of one. Each instantiation is a new named type of its own ([spec ↗](https://go.dev/ref/spec#Instantiations)): `Stack[int]` and `Stack[int64]` are as distinct as `int` and `int64`, and a value of one is not assignable to the other.

```go
// A generic type is a template for types: Stack[int] and Stack[string] are two
// distinct types, and %T prints each with its type argument. Inside a method
// the zero value of T is spelled var zero T, or *new(T), and a Pop that may
// have nothing to return says so with a second result.
//
//	go build a_generic_type_and_its_zero_value_go.go && ./a_generic_type_and_its_zero_value_go
package main

import "fmt"

type Stack[T any] struct{ items []T }

func (s *Stack[T]) Push(v T) { s.items = append(s.items, v) }

// Pop returns the top item, or T's zero value and false when there is none.
func (s *Stack[T]) Pop() (T, bool) {
	if len(s.items) == 0 {
		var zero T
		return zero, false
	}
	top := s.items[len(s.items)-1]
	s.items = s.items[:len(s.items)-1]
	return top, true
}

// Peek spells the zero value the other way: new(T) is a *T to a zeroed T.
func (s *Stack[T]) Peek() (T, bool) {
	if len(s.items) == 0 {
		return *new(T), false
	}
	return s.items[len(s.items)-1], true
}

// Set needs == on its keys, so T is comparable, not any.
type Set[T comparable] map[T]struct{}

func (s Set[T]) Add(v T)      { s[v] = struct{}{} }
func (s Set[T]) Has(v T) bool { _, ok := s[v]; return ok }

type Pair[K comparable, V any] struct {
	Key K
	Val V
}

func main() {
	var invoices Stack[string]
	invoices.Push("inv-1")
	invoices.Push("inv-2")
	for range 3 {
		v, ok := invoices.Pop()
		fmt.Printf("Pop: %q, ok = %t\n", v, ok)
	}

	var readings Stack[float64]
	v, ok := readings.Peek()
	fmt.Printf("Peek on empty Stack[float64]: %v, ok = %t\n", v, ok)
	var owners Stack[*string]
	p, ok := owners.Pop()
	fmt.Printf("Pop on empty Stack[*string]: %v, ok = %t\n", p, ok)

	tags := Set[string]{}
	tags.Add("paid")
	fmt.Printf("Set: Has(\"paid\") = %t, Has(\"void\") = %t, len = %d\n", tags.Has("paid"), tags.Has("void"), len(tags))

	fmt.Printf("%%T: %T, %T, %T, %T\n", invoices, &readings, tags, Pair[string, float64]{})
	fmt.Printf("%%T: %T, %T\n", Stack[[]byte]{}, Stack[Stack[int]]{})
	fmt.Printf("%%v of a zero Stack[int]: %v, %%+v: %+v\n", Stack[int]{}, Stack[int]{})
}
```

type Stack[T any] struct{ items []T }

	Val V
}

func main() {
	var invoices Stack
	var entry Pair[string]
	var wide Stack[int, string]
	_, _, _ = invoices, entry, wide
}
GO

say() { printf '$ %s\n' "$*"; }

say 'go build uninstantiated.go'
(cd "$dir" && go build uninstantiated.go) 2>&1

## What to do

- **Spell "nothing to return" as `var zero T` and return a `bool` beside it.** A sentinel value cannot exist for every `T`, and a panic on an empty stack is a decision the caller should have been allowed to make.
- **Constrain a map-backed type by `comparable`** and a slice-backed one by `any`: the constraint is whatever the type's own body needs, exactly as for a function ([A type parameter needs a constraint](../a_type_parameter_needs_a_constraint/README.md)).
- **Read the instantiation in `%T`** in logs, panics and failed assertions: `main.Stack[int]` and `main.Stack[int64]` are two types, and a `%T` that shows one where you expected the other is the whole diagnosis.
- **Instantiate at every use.** A variable, field or parameter of type `Stack` does not exist; write `Stack[Order]`, and let `%T` confirm it.

```go
// Kata: a Queue[T] with Push, Pop() (T, bool) and Len, drained past empty so
// that the zero value and the false show, and printed with %T.
//
//	go build a_generic_type_and_its_zero_value_kata_go.go && ./a_generic_type_and_its_zero_value_kata_go
package main

import "fmt"

type Queue[T any] struct{ items []T }

func (q *Queue[T]) Push(v T) { q.items = append(q.items, v) }

func (q *Queue[T]) Len() int { return len(q.items) }

// Pop takes from the front; on an empty queue it returns T's zero value and false.
func (q *Queue[T]) Pop() (T, bool) {
	if len(q.items) == 0 {
		var zero T
		return zero, false
	}
	front := q.items[0]
	q.items = q.items[1:]
	return front, true
}

type Order struct {
	ID  int
	Qty int
}

func main() {
	var orders Queue[Order]
	orders.Push(Order{ID: 7, Qty: 2})
	orders.Push(Order{ID: 12, Qty: 5})
	fmt.Printf("%T holds %d\n", orders, orders.Len())
	for range 3 {
		o, ok := orders.Pop()
		fmt.Printf("Pop: %+v, ok = %t\n", o, ok)
	}

	var names Queue[string]
	names.Push("pear")
	n, ok := names.Pop()
	fmt.Printf("%T: %q, ok = %t; then ", names, n, ok)
	n, ok = names.Pop()
	fmt.Printf("%q, ok = %t\n", n, ok)
}
```

## In other languages

- **Rust** — [What a generic is ↗](https://masiarek.github.io/rust-learning-library/22_Generics/what_a_generic_is/index.html): `Stack<i32>` and `Stack<String>` are distinct types, as in Go, and the compiler stamps out a copy per type where Go's compiler shares one copy per GC shape. Rust has no zero value: `pop` returns `Option<T>` — the type system's version of `(T, bool)`, and itself a [generic enum ↗](https://masiarek.github.io/rust-learning-library/22_Generics/generic_enums/index.html) — and a zeroed `T` needs a `T: Default` bound.
- **C++** — `std::stack<int>` is a class of its own per instantiation; `T{}` value-initializes, and the "maybe nothing" result is [`std::optional<T>` ↗](https://en.cppreference.com/w/cpp/utility/optional) rather than a second return value.
- **Java** — `Stack<Integer>` is one class at run time, because generics are [erased ↗](https://docs.oracle.com/javase/tutorial/java/generics/erasure.html): `new T()` and `new T[n]` are impossible, and `null` stands in for the missing value that Go spells `zero, false`.
